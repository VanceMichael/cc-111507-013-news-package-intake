# 编辑部授权供稿来源格式

支持 NewsML-G2 2.34 packageItem 的 groupSet、group/groupRef/itemRef、bag/sequence/alt 关系，itemRef 的资源定位在此网关表示为子 href，residref/version 是内容身份。package version 不替代 item version。catalog 的 scheme alias 作用于所在文档，不跨内容项继承；pubStatus usable/withheld/canceled 分开。内容项限 newsItem 的 contentSet 和 remoteContent/inlineXML；不执行嵌入脚本，不访问清单外资源。每条关系保留 group 路径、role 与备选组身份，缺素材不自动改变原供稿选择。

`fixtures/scenarios.json` 给出本机来源入口和允许读取的资源；`GET /manifest` 返回同样的来源描述。`GET /trace` 返回当前进程内真实来源访问记录。资源接口为 `GET /files/百分号编码的资源名`，支持单段 Range、ETag 和 If-Match；资源名必须出现在来源清单中。数据不是新闻原文，不连接真实客户或设备。

收件实现边界（structured 模式）：

- 只自动请求来源清单（manifest resources）中的 href；清单外 itemRef href 登记 resource-outside-manifest 问题且不发请求，newsItem 内 remoteContent 一律登记为 not-traversed，不跟随任何契约之外的链接。同一 href 只请求、落盘一次。
- catalog scheme alias 按文档独立构建：包的别名只解释包内 qcode，newsItem 自带 catalog 独立解释，未登记别名保留原始 qcode 并标记 unresolved，不猜测 URI。标准别名仅覆盖 pgrmod（组模式）与 stat（出版状态），并在解析结果中标注 standard-catalog。
- pubStatus 三态分开保留：usable 才允许 editable；withheld/canceled 不阻断字节收件，但 coverage.editable 为假并保留状态证据。内容项自身 pubStatus 不可用时单独记录 item-not-usable。
- 组关系按 XML 文档顺序遍历，bag/sequence/alt 模式、group 路径、组内 ordinal、备选组身份全部进入记录；groupRef 循环按活动组栈检测并截断，悬空引用定位为问题，不抛异常丢失已解析关系。
- 内容项解释范围限 newsItem 的 contentSet/inlineXML/remoteContent：inlineXML 保留原始片段与元素名，检测到脚本只标记不执行；嵌套 packageItem 或其他 XML 根保留原文并标记 unsupported-item-type；非 XML 素材按二进制字节留存。
- itemRef 声明版本与 newsItem 实测版本分别记录，不一致时 item-version-mismatch 为阻断问题；包版本永远不替代内容项版本。

格式参考：https://www.iptc.org/std/NewsML-G2/guidelines/。本项目只承诺上文列出的范围；未列出扩展应保留原文并明确不支持，不能假装完整解析。
