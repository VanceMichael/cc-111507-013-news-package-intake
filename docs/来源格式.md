# 编辑部授权供稿来源格式

支持 NewsML-G2 2.34 packageItem 的 groupSet、group/groupRef/itemRef、bag/sequence/alt 关系，itemRef 的资源定位在此网关表示为子 href，residref/version 是内容身份。package version 不替代 item version。catalog 的 scheme alias 作用于所在文档，不跨内容项继承；pubStatus usable/withheld/canceled 分开。内容项限 newsItem 的 contentSet 和 remoteContent/inlineXML；不执行嵌入脚本，不访问清单外资源。每条关系保留 group 路径、role 与备选组身份，缺素材不自动改变原供稿选择。

`fixtures/scenarios.json` 给出本机来源入口和允许读取的资源；`GET /manifest` 返回同样的来源描述。`GET /trace` 返回当前进程内真实来源访问记录。资源接口为 `GET /files/百分号编码的资源名`，支持单段 Range、ETag 和 If-Match；资源名必须出现在来源清单中。数据不是新闻原文，不连接真实客户或设备。

格式参考：https://www.iptc.org/std/NewsML-G2/guidelines/。本项目只承诺上文列出的范围；未列出扩展应保留原文并明确不支持，不能假装完整解析。
